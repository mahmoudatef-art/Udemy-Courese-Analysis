# Udemy Courses Analysis

## Project Overview
This project focuses on analyzing Udemy courses data using Python.

The analysis includes:
- Data Cleaning
- Handling Missing Values
- Feature Engineering
- Exploratory Data Analysis (EDA)
- Data Visualization using Plotly

---

## Tools & Libraries
- Python
- Pandas
- NumPy
- Plotly
- Jupyter Notebook

---

## Key Insights
- Course publishing increased significantly after 2014.
- Web Development courses had the highest number of published courses.
- Paid courses generated higher subscriber counts.
- Course trends varied by quarter and category.
